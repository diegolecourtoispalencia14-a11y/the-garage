# Dynamic Find-Skills Engine

## Operational Workflow
1. **Query**: When new project requirements arise (e.g. Meta Commerce Manager integration, MTB route blog, bike rental booking), query `skills.sh` for exact community-tested skills.
2. **Evaluation**: Validate that proposed skills strictly adhere to zero-cost, commercial-allowed, and zero-JS performance guidelines.
3. **Integration**: Incorporate new skills into `.skills/` to provide immediate specialized assistance.
