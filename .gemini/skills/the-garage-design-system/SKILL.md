# The Garage Design System Skill

When modifying or generating frontend components for The Garage:
1. **Always reference `DESIGN.md`** at the project root for color tokens, spacing scales, and typography.
2. **Never overcrowd UI:** Use generous padding (4rem - 6rem on sections, 2.5rem on grids).
3. **Use authentic photos only:** Never use synthetic vector diagrams for bike catalog or social posts.
4. **Motion:** Apply `cubic-bezier(0.16, 1, 0.3, 1)` to all hover interactions.
5. **No fabricated metrics:** Never invent like counts or fake social numbers.
